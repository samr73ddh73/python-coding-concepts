# Bit Manipulation

Binary representations and bitwise operations.

## Basics
- **AND (&)**: Both bits are 1
- **OR (|)**: At least one bit is 1
- **XOR (^)**: Bits are different
- **NOT (~)**: Flip all bits
- **Left Shift (<<)**: Multiply by 2
- **Right Shift (>>)**: Divide by 2

## Python Quirks
- No fixed bit width (unlimited precision)
- Negative numbers have infinite 1s at start
- Right shift on negative numbers fills with 1s

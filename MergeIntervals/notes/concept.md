# Merge Intervals

Three core interval patterns with different sorting strategies.

## Pattern 1: Sort by Start - Merge Overlapping
Sort intervals by start time, then merge overlapping ones.

## Pattern 2: Sort by End - Maximum Non-overlapping
Sort by end time and greedily select intervals that don't overlap.

## Pattern 3: Line Sweep - Count Concurrent Intervals
Use events to track overlapping intervals at any point in time.

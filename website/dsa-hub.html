⏱️ Time Complexity Mapping

Choose algorithm based on constraint:

n ≤ 12 → O(n!) possible n ≤ 25 → O(2^n) possible n ≤ 100 → O(n^4) possible n ≤ 500 → O(n^3) possible n ≤ 10^4 → O(n^2) possible n ≤ 10^6 → O(n log n) possible n ≤ 10^8 → O(n) possible n > 10^8 → O(log n) or O(1) needed

Key Rule: Time complexity should be < 10^8 operations (≈ 1 second)

📊 BigO Cheatsheet

Constant: O(1) - Array access, dict lookup Logarithmic: O(log n) - Binary search Linear: O(n) - Single loop Linearithmic: O(n log n) - Sorting Quadratic: O(n²) - Nested loops Cubic: O(n³) - Triple nested loops Exponential: O(2^n) - Recursive without memo Factorial: O(n!) - Permutations

🔑 Dictionary (HashMap)

➕ Set

🔄 DefaultDict

Auto-initializes missing keys (no KeyError!)

from collections import defaultdict d = defaultdict(int) # Missing key → 0 d = defaultdict(list) # Missing key → [] d = defaultdict(set) # Missing key → set() d["new_key"] += 1 # Works! d["new_key"].append(x) # Works!

🎯 Algorithm Patterns

Master fundamental patterns used in DSA interviews

➡️ Two-Pointer

When: Subarrays, palindromes, merging, 3Sum

TC/SC: O(n) / O(1)

# Same direction slow, fast = 0, 0 while fast < n: if valid: slow += 1 fast += 1 # Opposite directions left, right = 0, n-1 while left < right: ...
Array

🪟 Sliding Window

When: Max/min subarray, substring with property

TC/SC: O(n) / O(k)

left = 0 for right in range(n): # Add element at right while invalid: # Remove element at left left += 1 # Update answer
Array

🌊 BFS

When: Shortest path (unweighted), level-wise

TC/SC: O(V+E) / O(V)

from collections import deque q = deque([start]) visited = {start} while q: node = q.popleft() for neighbor in graph[node]: if neighbor not in visited: visited.add(neighbor) q.append(neighbor)
Graph

🌳 DFS

When: Cycles, topological sort, paths

TC/SC: O(V+E) / O(V)

def dfs(node, visited): visited.add(node) for neighbor in graph[node]: if neighbor not in visited: dfs(neighbor, visited) # Or iterative with stack stack = [start] while stack: node = stack.pop() ...
Graph

🌲 Tree Traversal

When: Paths, heights, construction

TC/SC: O(n) / O(h)

# DFS Pre-order (top-down) def dfs(node): if not node: return process(node) dfs(node.left) dfs(node.right) # DFS Post-order (bottom-up) def dfs(node): if not node: return dfs(node.left) dfs(node.right) process(node)
Tree

💰 DP: Knapsack

When: Optimize capacity/amount

TC/SC: O(n×W) / O(W)

# 0/1 Knapsack dp = [0] * (capacity + 1) for item in items: for c in range(capacity, weight-1, -1): # BACKWARD! dp[c] = max(dp[c], dp[c-weight] + value)
DP

🔍 Binary Search

When: Exact match, bounds, answer space

TC: O(log n)

left, right = 0, n-1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1
Search

🔙 Backtracking

When: Permutations, combinations, puzzles

TC: O(n!)

def backtrack(path, choices): if not choices: result.append(path[:]) return for choice in choices: path.append(choice) backtrack(path, remaining) path.pop() # CRITICAL!
Recursion

⚡ Tricks & Common Gotchas

Critical mistakes that trip up candidates

⚠️ Array Indexing Trick

Pattern: Elements in range [0, n)?

# Use array indices as hashmap for i in range(n): idx = abs(arr[i]) - 1 arr[idx] = -arr[idx] # Mark visited

When: Find duplicates, missing numbers

Critical

⚠️ DFS Cycle Detection

Pattern: Directed graphs need pathVisited!

# ❌ Parent check FAILS for directed # ✅ Use pathVisited (current path) def dfs(node, visited, pathVisited): visited.add(node) pathVisited.add(node) for neighbor in graph[node]: if neighbor in pathVisited: return True # CYCLE! dfs(neighbor, visited, pathVisited) pathVisited.remove(node)
Critical

⚠️ Backtracking: Always Pop!

Trap: Mutable lists need cleanup

# ❌ Forgetting pop() paths.append(node) dfs(left) # left branch sees node dfs(right) # right branch ALSO sees node! # ✅ Always pop paths.append(node) dfs(left) paths.pop() # Remove before right! dfs(right)
Critical

⚠️ DP: Backward vs Forward

0/1 Knapsack: Iterate backward!

# ❌ Forward: Allows item multiple times for c in range(weight, capacity+1): dp[c] = max(dp[c], dp[c-w] + val) # ✅ Backward: Each item once for c in range(capacity, weight-1, -1): dp[c] = max(dp[c], dp[c-w] + val)
Critical

⚠️ String Building O(n²)

Trap: += in loops is slow!

# ❌ O(n²) - new string each time result = "" for ch in s: result += ch # ✅ O(n) result = ''.join(s) # Or with filtering: ''.join(c for c in s if c.isalnum())
Performance

⚠️ BFS: Mark When Enqueueing

Trap: Marking at dequeue adds duplicates

# ❌ Can add same node twice q.append(neighbor) visited.add(neighbor) # At dequeue # ✅ Mark immediately if neighbor not in visited: visited.add(neighbor) q.append(neighbor)
Correctness

⚠️ Mutable Default Arguments

Trap: Default lists shared across calls!

# ❌ WRONG def add_to_list(x, lst=[]): lst.append(x) return lst add_to_list(1) # [1] add_to_list(2) # [1, 2] (same list!) # ✅ CORRECT def add_to_list(x, lst=None): if lst is None: lst = [] lst.append(x) return lst
Python

⚠️ Coin Change Greedy Fails

Trap: Greedy doesn't always work!

# ❌ Greedy FAILS coins = [1, 3, 4], amount = 6 Greedy: 4 + 1 + 1 = 3 coins Optimal: 3 + 3 = 2 coins # ✅ Use DP dp = [float('inf')] * (amount + 1) dp[0] = 0 for i in range(1, amount + 1): for coin in coins: if i >= coin: dp[i] = min(dp[i], dp[i-coin] + 1)
Critical
